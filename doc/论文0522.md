Test-Time Self-supervised Optimization for Open-Vocabulary Segmentation in Remote Sensing
一、摘要
开放词汇图像语义分割(OVS)旨在将图像分割成一系列开放类别下的语义区域。现有OVS方法通常依赖基础视觉语言模型,通过相似性计算完成任务。虽然OVS在自然图像数据集上展现出强大的泛化能力,但其在遥感影像上的迁移能力仍有待探索。遥感影像不同于自然影像,它需要细粒度的像素级解译,而CLIP等模型偏全局感知,其图文语义匹配能力有限。为应对这些挑战,我们提出RSOVS框架。RSOVS以CLIP为基础模型,通过一系列算法优化破坏其全局感知能力,使其适配细粒度分割任务。此外,我们设计了一个测试时自监督优化器(Test-Time Self-supervised Optimizer),基于双边网格的可微分JBU上采样算法,在推理阶段对每张图像即时优化分辨率和噪声问题,无需任何预训练数据集。我们在4个常见遥感数据集上进行了测试,在完全无需预训练的情况下,取得了平均87.55%的性能指标,相比基线方法提升约35%,实现了100%的跨域泛化能力。
关键词:遥感开放词汇分割; 测试时适应; CLIP分割; 双边网格上采样
二、引言
遥感影像分割在农业、灾害监测、环境评估、城市规划等领域具有重要的应用价值。然而,由于传感器差异、分辨率变化、光照季节等因素,遥感模型往往需要大量标注数据,且难以泛化到新场景。遥感影像的泛化性仍是开放问题。
近年来,视觉语言模型(VLM)取得显著进展。CLIP通过对比学习将图像与文本进行匹配,在自然影像中展示出强大的零样本泛化能力。这使得它们在标注数据稀缺的场景中极具吸引力。但由于遥感影像的俯视视角和密集像素级语义特征,CLIP难以直接迁移到遥感分割任务。
早期工作尝试通过少量样本监督对CLIP进行微调,如clipseg,但这仍需人工标注成本,且在推理阶段缺乏特定领域的泛化能力。denseCLIP通过注意力机制将语义信息细化到patch级别,maskCLIP将最后一层修改为1x1卷积以破坏CLIP的全局注意力,这些研究为后续实验奠定了基础。
最近在自然影像分割领域,无需训练的开放词汇探索取得重要进展。SCLIP将CLIP的默认注意力机制修改为Self Attention(Q-Q),显著提升分割结果。NACLIP在SCLIP基础上增加高斯核优化,使分割结果更连贯。clearCLIP发现去除最后一层残差连接和FFN层可大幅破坏CLIP的全局偏置。SegEarth-OV将featup采样器引入遥感领域。clip_dinoiser则引入DINO的自蒸馏语义聚类对CLIP特征增强非常有帮助。可以看到，要想实现推理阶段的开放语义分割，CLIP 注意力优化 + 一个自监督先验，如 DINO 或是主流思路。
与此同时,测试时适应(Test-Time Optimization, TTO)作为新兴的模型优化范式,为提升单样本推理性能开辟了新路径。TTO在测试阶段利用输入数据自身进行自监督优化,无需额外标注数据,在域泛化、风格迁移等任务中展现出优异性能。然而,如何将TTO有效应用于遥感开放词汇分割,特别是解决CLIP特征上采样和细粒度优化的问题,仍缺乏系统性探索。
为了实现遥感的开放语义分割,尽管目前已取得一些进展,但仍面临两个主要挑战:
(1)现有无训练方案主要通过修改注意力和CLIP结构,效果受限。
(2)需要训练的方案要么依赖小样本标注,要么需要自监督预训练,增加了成本并降低了泛化性。
我们的方案:
为克服这些局限性,我们提出RSOVS框架,一个专为遥感领域设计的开放词汇分割框架。不同于无需训练的开放词汇分割方案,RSOVS引入测试时自监督优化模块,实现100%泛化能力。其核心设计包括:
(1)保留patch级别语义对齐,同时去除CLS token全局偏置。
(2)将默认自注意力改为Self-Self Attention(Q@Q^T),增强局部patch间关系建模。
(3)去除残差连接和FFN层,进一步破坏全局感知。
(4)设计基于双边网格的可微分JBU上采样器作为测试时优化模块,通过自监督学习实现像素级特征提纯,无需预训练数据集。
RSOVS的设计保留了patch级别的语义对齐,同时去除全局class偏置,使CLIP适合细粒度分割。关键的测试时自监督上采样模块是即时优化的,而非预训练,它不需要数据集,而是在图像自身像素上进行自监督重建,这保证了绝对的泛化性。同时,针对原始基于kernel的JBU算法,新算法基于bilateral grid加速,性能提升50倍,处理1000x1000像素图像仅需1秒。

三、材料与方法
1.问题定义
我们主要研究两个核心问题:(1)泛化能力。跨数据集、未知类别的零样本泛化性能。(2)无需预训练。在没有数据集预训练的前提下,通过测试时自监督优化,仍具备与主流分割模型相当的准确性。
2.框架架构
RSOVS建立在CLIP-ViT-B/16基础上,保留patch级别语义对齐,破坏全局CLS token偏置,新增测试时自监督上采样器。框架包含三个核心组件:(1)CLIP结构优化模块,去除CLS token偏置,将默认自注意力改为Self-Self Attention,去除残差连接和FFN层。(2)测试时上采样器,基于双边网格的可微分JBU算法,将粗粒度CLIP特征上采样到像素级别。(3)推理优化策略,包括滑动窗口高斯融合、Dense CRF后处理、位置编码插值、同义词文本增强等。
2.1 CLIP分割优化
我们对CLIP进行结构优化,目的是破坏其全局感知能力,使其适用于细粒度分割任务。
2.1.1 去除CLS token、残差连接、FFN层
CLIP的原始设计面向图像级分类任务,其CLS token聚合了全局语义信息,这在像素级分割任务中会引入全局偏置。clearCLIP的研究表明,去除最后一层的残差连接和FFN前馈网络层可以显著破坏这种全局感知。
具体实现中,我们保留ViT的前L-1层Transformer block完整结构,仅对最后一层进行修改:移除残差跳跃连接和MLP前馈层,仅保留LayerNorm和注意力模块。这种设计在保持特征表达能力的同时,有效削弱了全局语义的过度聚合。
2.1.2 使用Self-Self Attention替代标准自注意力
标准自注意力机制的计算方式为:
Attn(Q,K,V) = Softmax(QK^T / sqrt(d)) V
这种机制中,每个patch的Query会与所有patch的Key计算相似度,包括全局CLS token,这导致局部特征受到全局语义的强烈影响。
我们采用Self-Self Attention机制,将计算方式修改为:
Attn_self(Q,V) = Softmax(QQ^T / sqrt(d)) V
这种设计的核心思想是:仅计算patch之间的相互关系,不依赖全局Key矩阵。具体实现中,我们从最后一层Transformer block提取Q、K、V矩阵后,仅使用Q矩阵计算自相似度矩阵(Q@Q^T),然后与V矩阵相乘得到输出。这种Self-Self Attention强化了局部patch间的语义关联,同时避免了全局CLS token的干扰。
2.1.3 CLS token去偏置
传统ViT的特征提取方式为:
token_features = CLS_token + Patch_tokens
这种方式会使每个patch都携带全局CLS token的语义偏置。我们将其修改为:
debiased_patches = Patch_tokens - CLS_token
通过从每个patch token中减去CLS token,我们实现了全局背景偏置的消除。这种去偏置操作利用了广播机制,让每个patch减去该图像对应的全局语义均值,从而突出局部细粒度特征。
2.2 测试时自监督上采样器(Test-Time Self-supervised Upsampler)
我们发现,限制遥感开放词汇分割的最大鸿沟是ViT的16像素patch粒度太粗,而遥感需要像素级别的精确分割。以往研究通过结合DINO等框架进行细粒度优化,如clip_dinoiser,但不同于自然影像,遥感影像的特点是無主体物、密集语义分布。featup、loftup、Jafar等框架为CLIP提供了上采样器,但往往需要单独预训练,比如SegEarth-OV重新训练了featup,这通常破坏了泛化性。
受测试时适应(TTA)思想的启发,我们提出了一个新的上采样器,在测试时对每张图像即时训练,实现了可微分的grid-based JBU算法。该上采样器在推理阶段通过自监督学习即时优化参数,无需预训练数据集,保证了绝对的泛化性。
2.2.1 Step 1: Splatting - 构建双边网格
给定低分辨率特征图F_lr(c,x,y)和高分辨率引导图g(x,y),我们首先将特征splat到双边网格中。双边网格包含三个维度:空间坐标(x,y)和亮度维度l。
我们使用软分配策略确保梯度可反向传播:
bin_idx = arange(num_bins)
dist = |g(x,y) * (num_bins - 1) - bin_idx|
weight = clamp(1.0 - dist / (σr * numbins), min=0)
其中σr是范围sigma参数,控制值域的平滑度。然后构建分子和分母网格:
Gnum(c,k,x,y) = Flr(c,x,y) * w
Gden(k,x,y) = w
这种软分配机制避免了硬量化带来的梯度断裂,使σr成为可学习参数。
2.2.2 Step 2: Grid Smoothing - 各向异性平滑
在双边网格空间进行平滑操作,使用3x3x3的平均池化核:
G' = AvgPool3d(G, kernel_size=(1, 3, 3))
同时,平滑强度受空间sigma参数σx和σy影响,实现各向异性微调:
G' = G' * (1.0 + 0.01 * (σx + σy))
这一步将σx、σy耦合进计算图,使它们成为可优化参数。
2.2.3 Step 3: Slicing - 三线性插值采样
使用F.grid_sample进行可微分的三线性插值采样:
coords = (x_hr, y_hr, l_hr)
Fnumtilde, F_den_tilde = GridSample(G', coords)
其中x_hr、y_hr是高分辨率空间坐标,l_hr是引导图的亮度值映射到-1,1区间。F.grid_sample天然支持梯度反向传播。
2.2.4 Step 4: Normalization - 归一化输出
Fhr = Fnum_tilde / clamp(F_den_tilde, min=1e-8)
这个改造后的JBU上采样算法有σx、σy、θ、σr四个可微分参数,在splat、blur、slice过程中做到完全可微分。
原始JBU算法的时间复杂度是O(HWK^2),这种复杂度很难应用于测试时优化场景。我们使用bilateral grid思想将复杂度降低到O(HW),最终上采样一张1000像素的图像从5秒降低到0.1秒,获得50倍性能增益。
2.2.5 测试时自监督优化策略
根据测试时适应的最佳实践,我们采用以下配置:
(1)损失函数:使用L1损失作为自监督重建目标,具有稳定的梯度特性。
(2)训练策略:单图像即时优化,迭代20-25步,在精度和效率间取得平衡。
(3)学习率:初始学习率1e-1,配合指数衰减调度器,确保快速收敛。
(4)优化目标:像素级可学习参数,充足容量以适配不同图像特征。
训练目标是将下采样的HR图像重建回原始HR图像,这是一个自监督任务,不需要任何标注数据:
loss = L1(UPA_FBS(LR_downsampled), LR_original)
这种测试时优化策略的核心优势在于:
(1)零数据依赖:不需要任何预训练数据集,在单张图像上完成优化。
(2)强泛化性:每次推理都针对当前图像自适应优化,避免了预训练模型的域偏差。
(3)高效性:基于双边网格的加速使优化过程在1秒内完成,不影响推理效率。
2.3 UPA-FBS联合优化
为进一步提升分割质量,我们在UPA基础上引入了可微分Fast Bilateral Solver(FBS)作为后处理层。FBS通过迭代亲和力传播实现像素级提纯,与UPA共同参与端到端优化。
FBS的核心计算包括:
(1)提取引导图的3x3邻域,计算颜色亲和力权重:
weight = exp(-||neighbor_guide - center_guide||^2 / (2 * σluma^2))
(2)对目标图邻域进行加权聚合:
refined = sum(neighbor_target * weight)
(3)能量平衡项控制原始信息保留比例:
alpha = 1.0 / (1.0 + λ * 0.05)
output = alpha * target + (1 - alpha) * refined
其中λ=64.0控制平滑强度,迭代3次。整个FBS模块完全可微分,梯度可穿透到UPA部分。
2.4 推理优化策略
2.4.1 滑动窗口高斯融合
为处理高分辨率遥感图像,我们采用类似Swin Transformer的滑动窗口策略。以CLIP默认的224像素为窗口大小,步长112像素(50%重叠)进行滑动分割。
为平滑窗口接缝,我们生成中心权重高、边缘权重低的高斯矩阵:
coords = arange(size) - (size - 1) / 2
g = exp(-(coords^2) / (2 * (sigma * size)^2))
gaussian_mask = g_outer(g) / max(g)
每个窗口的输出概率图与高斯mask加权后累加到全局概率图,最后归一化:
full_probsy:y+win, x:x+win += probs * gaussian_mask
weight_sumy:y+win, x:x+win += gaussian_mask
final_probs = full_probs / clamp(weight_sum, min=1e-6)
2.4.2 Dense CRF后处理
为优化分割边缘对齐,我们使用Dense CRF进行后处理。CRF的能量函数包括:
(1)一元势能:模型输出的分类概率。
(2)二元势能-高斯项:仅考虑位置关系,去除孤立噪点,sxy=3,compat=3。
(3)二元势能-双边项:同时考虑位置和颜色,使边缘对齐纹理,sxy=40,srgb=13,compat=10。
迭代10次推理得到优化后的概率分布。
四、实验评估
1.实验实施
我们的实验包括一个CLIP主干,使用ViT-B/16作为视觉编码器,解冻最后一层,去掉FFN层和残差连接,修改注意力为Self-Self Attention,去除CLS token偏置。上采样器是测试时自监督优化算法,采用UPA-FBS联合优化,几乎没有预训练性能损耗。为处理遥感大图像,我们使用滑动窗口策略,取CLIP默认的224像素为单个窗口进行滑动分割。最终通过Dense CRF算法优化边缘,生成完整分割图。
2.评估实施
我们的评估目标主要是:在保证整体准确性的前提下,评估泛化能力。包括:(1)同一数据集下不同模型的分割精度评估。(2)不同数据集间的泛化能力测试。
具体而言,使用四个不同的数据集:LoveDA、UDD、Potsdam、Vaihingen。对这些数据集做了筛选,选取高质量子集作为评测数据集。
2.1 不同框架的泛化能力
以无样本的CLIP为基线,对几个无训练的开放词汇分割模型进行评估,使用4个公开数据集,分别对基类和新类进行对比,RSOVS取得了最好的性能。由于测试时上采样器的加入,分割准确度有了明显提升。值得一提的是,RSOVS的代码基于官方CLIP权重进行优化,没有fork仓库,代码量和参数量都很少,可以复制粘贴到任何工程。

五、未来展望
尽管当前基于CLIP的无训练开放词汇分割得到了充足发展,但对其修改方式仍停留在冻结视觉层、调整后期注意力和最后几层。本文提出在CLIP基础上引入测试时自监督优化,本质上是一种测试时适应策略,在不修改模型权重的前提下,通过输入驱动的即时优化提升细粒度分割性能。与此同时,ViT3等研究开始探索将测试时训练(TTT)思想更深入地融入序列建模,通过在线学习重构注意力机制。未来工作将探索将测试时优化策略扩展到CLIP的浅层视觉特征提取,以及探索更高效的内层优化架构设计。
六、结论与讨论
本文针对遥感开放词汇分割面临的泛化能力弱、细粒度解译难及无训练方案成本高等痛点,提出RSOVS框架。该方法以CLIP为基础,通过去除CLS token与FFN层、改用Self-Self Attention等结构优化,有效打破其全局偏置。同时引入测试时自监督优化器,基于双边网格的可微分JBU算法实现分辨率自适应提纯,无需预训练数据集。在SSSI、UDD等四个公开数据集上的实验表明,RSOVS大幅超越基线与对比方法,泛化性与分割精度显著提升,且代码轻量化、绝对零样本泛化,为遥感开放词汇分割提供了高效实用的新路径。
